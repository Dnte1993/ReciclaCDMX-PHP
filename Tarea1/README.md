# ReciclaCDMX
Primera versión estructural y visual del portal ReciclaCDMX, una plataforma para la gestión y consulta de reciclaje en la Ciudad de México, desarrollado para la materia de Programación Web.

## Versión
0.1.0

## Tecnologías
* HTML5 (Estructura semántica del portal)
* CSS3 (Estilos visuales)

## Requisitos
* Un navegador web actualizado (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).
* Opcional: Un editor de código como Visual Studio Code para inspeccionar o modificar la estructura.

## Ejecución
1. Extraer el contenido del archivo .zip.
2. Abrir la carpeta raíz del proyecto.
3. Dar doble clic en el archivo `index.html` para abrir el portal directamente en el navegador web.
4. Utilizar el menú de navegación principal para desplazarse por el resto de las páginas.

## Estructura
* `css/`: Carpeta que contiene la hoja de estilos (`style.css`).
* `img/`: Carpeta destinada a almacenar las imágenes y recursos gráficos del portal.
* `index.html`: Página principal de ReciclaCDMX.
* `informacion.html`: Sección de presentación de información sobre materiales reciclables.
* `detalle.html`: Página de detalle específico sobre el reciclaje de plástico PET.
* `contacto.html`: Sección adicional con formulario de contacto estático.
* `README.md`: Documentación del estado actual y versiones del proyecto.

## Funcionalidades actuales
* Estructura base de 4 páginas interconectadas.
* Navegación estática clara, funcional y consistente entre todas las secciones.
* Interfaz inicial utilizando etiquetas semánticas de HTML5.
